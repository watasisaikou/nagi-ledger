# Runtime dependency of the MCP server (server.py) only.
#
# The hook scripts (session_brief.py, dispatch_guard.py, hook_ingest.py,
# goal_gate.py) are deliberately standard-library only, so they run under
# any Python interpreter without an environment being activated. That is a
# design constraint, not an accident: a hook that needs a virtualenv is a
# hook that silently stops working when the wrong interpreter is used.
#
# Pinned below 2.0: mcp 2.x removed the FastMCP API this server is built on
# (`mcp.server.fastmcp.FastMCP`). Tested against 1.29.
#
# ASCII ONLY. pip reads this file with locale.getpreferredencoding() when
# there is no BOM, so a non-ASCII byte here makes `pip install -r` fail
# outright on any machine whose default codepage is not UTF-8 or cp1252 --
# cp932, cp949 and gbk all reject the em dash this file used to contain.
# See tests/test_packaging.py, which enforces it.
mcp>=1.29,<2
